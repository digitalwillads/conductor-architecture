The Verification Loop

Agents do the work. Verifiers decide if it is right. Will approves what leaves the building. Every client gets one thread a day that checks, fixes, and checks again, and every miss turns into a new check.

The verifier is a tool

The agent calls the check itself, in its own thread, as often as it needs. It never grades its own work: code and Jev decide if the work is right.

Nothing leaves without proof

An email or an account change goes out only when the transcript shows Will saw that exact text and said yes in plain words. The guard blocks every other way.

Misses become checks

"Be more careful" is never the fix. Each miss becomes a check with a test from the real case, and the change gate makes sure no check gets looser without Will.

One thread per client per day. Events from 08:00 to 02:00 ET; held overnight. Every action is in the thread, so Will can audit all of it.
